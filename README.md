# بوت واتساب - مؤسسة الخدمات الإلكترونية

بوت واتساب يستقبل العملاء، يعرض الأقسام والخدمات، يوضح المستندات المطلوبة
لكل خدمة، يستقبل المستندات، ثم يؤكد للعميل أنه سيتم التواصل معه خلال 24 ساعة.

يعمل عبر **WhatsApp Cloud API الرسمي من ميتا** — بدون أي خطر حظر للرقم،
و**مجاني** لحالة الاستخدام هذه: المحادثات التي يبدأها العميل والرد عليها
خلال 24 ساعة لا تُحتسب عليها رسوم.

## طريقة عمل البوت

1. العميل يرسل أي رسالة → تظهر له القائمة الرئيسية (3 أقسام + متابعة طلب سابق).
2. يختار القسم برقمه → تظهر قائمة خدمات القسم (بدون أسعار).
3. يختار الخدمة برقمها → تظهر المستندات المطلوبة فقط.
4. يرسل المستندات (صور/ملفات) → بعد آخر مستند بـ 30 ثانية يصله تأكيد
   تلقائي برقم الطلب وأنه **سيتم التواصل معه خلال 24 ساعة**.
   (أو يكتب *تم* للتأكيد فوراً دون انتظار).
5. أي مستند يصل بعد اكتمال الطلب (خلال ساعة) يُضاف للطلب الأخير تلقائياً.

لا يطلب البوت أي بيانات من العميل (لا اسم ولا جوال ولا هوية) —
رقم واتساب العميل يصل للموظف تلقائياً مع إشعار الطلب.

## المميزات

- 🏠 قائمة رئيسية بالأقسام الثلاثة + متابعة طلب سابق.
- 📋 أكثر من 55 خدمة مقسّمة على 3 أقسام مع المستندات المطلوبة لكل خدمة.
- 📎 استقبال المستندات (صور/ملفات/نصوص) وحفظها.
- ⏱️ تأكيد تلقائي بعد إرسال المستندات (بدون خطوات إضافية على العميل).
- 🔖 رقم طلب لكل عميل مع إمكانية المتابعة لاحقاً.
- 🔔 إشعار الموظف تلقائياً بكل طلب جديد على واتساب مع رقم العميل (اختياري).
- ✅ رسمي 100% (Cloud API) — لا خطر حظر، ولا يحتاج متصفحاً أو مسح QR.

## الأقسام والخدمات

| القسم | الخدمات |
|-------|---------|
| 1️⃣ خدمات الأعمال والمنشآت | فتح سجل تجاري، ملفات (مكتب عمل/قوى/زكاة/تأمينات/غرفة)، نقل كفالة، رخص بلدية، تأشيرات، مدد، ضريبة، شطب... |
| 2️⃣ خدمات المواطنين | وكالات، حصر ورثة، صكوك، بنك التنمية، حساب المواطن، الضمان، تجديد جواز/أحوال، تسجيل تعليمي، قياس، حافز... |
| 3️⃣ خدمات العمال والمقيمين | أبشر، خروج وعودة، إقامة، رخصة عمل، زيارة عائلية، مواعيد مرور/نيابة، ناجز، كهرباء... |

الأسعار محفوظة في `src/config/services.js` (تصل للموظف في إشعار الطلب
لكنها **لا تظهر للعميل**).

## الإعداد من طرف ميتا (مرة واحدة)

### 1. إنشاء التطبيق

1. سجّل في [developers.facebook.com](https://developers.facebook.com) بحساب فيسبوك.
2. **My Apps ← Create App** واختر النوع **Business**.
3. من صفحة التطبيق أضف منتج **WhatsApp**.

بمجرد إضافة WhatsApp تحصل مجاناً على **رقم تجريبي** وتوكن مؤقت —
يكفي لتجربة البوت كاملاً قبل ربط الرقم الحقيقي.

### 2. نسخ القيم إلى `.env`

من صفحة **WhatsApp ← API Setup** انسخ:

- **Temporary access token** → `WHATSAPP_TOKEN`
- **Phone number ID** (رقم طويل تحت اسم الرقم) → `PHONE_NUMBER_ID`

```bash
cp .env.example .env
# ثم املأ القيم
```

> في التجربة بالرقم التجريبي: أضف رقمك في خانة **To** بصفحة API Setup
> (ميتا تسمح بمراسلة 5 أرقام تجريبية كحد أقصى قبل ربط رقم حقيقي).

### 3. تثبيت وتشغيل البوت

```bash
npm install
npm start
```

سيعمل السيرفر على المنفذ 3000 (أو `PORT` من `.env`).

### 4. توصيل الويب هوك

ميتا تحتاج رابط HTTPS عام تصلها منه رسائل العملاء. **للتجربة على جهازك**
استخدم نفق cloudflared (مجاني وبدون تسجيل):

```bash
# حمّل cloudflared من موقع Cloudflare ثم:
cloudflared tunnel --url http://localhost:3000
```

سيعطيك رابطاً مثل `https://xxxx.trycloudflare.com`. في لوحة ميتا:
**WhatsApp ← Configuration ← Webhook ← Edit**:

- **Callback URL**: `https://xxxx.trycloudflare.com/webhook`
- **Verify token**: نفس قيمة `VERIFY_TOKEN` في `.env`

اضغط **Verify and save**، ثم في **Webhook fields** فعّل الاشتراك في
حقل **messages**.

أرسل رسالة واتساب للرقم التجريبي — يجب أن يرد البوت بالقائمة الرئيسية ✅

### 5. الانتقال للإنتاج (رقم المكتب الحقيقي)

1. من **WhatsApp ← API Setup ← Add phone number** أضف رقم المكتب.
   ⚠️ الرقم يجب ألا يكون مسجلاً في تطبيق واتساب العادي (أو احذف حسابه أولاً).
2. التوكن المؤقت ينتهي خلال 24 ساعة — أنشئ **توكن دائم**:
   من [business.facebook.com](https://business.facebook.com) ←
   **Settings ← System users** ← أنشئ مستخدم نظام ← **Generate token**
   باختيار تطبيقك وصلاحية `whatsapp_business_messaging`.
3. استبدل القيم في `.env` بالتوكن الدائم و`Phone number ID` للرقم الحقيقي.
4. انقل البوت لسيرفر يعمل باستمرار (انظر الفقرة التالية).

## إبقاء البوت شغالاً باستمرار

البوت سيرفر ويب يجب أن يظل شغالاً ومتاحاً برابط HTTPS ثابت:

- **أفضل خيار مجاني دائم:** سيرفر **Oracle Cloud Always Free** —
  ثبّت عليه Node.js وشغّل البوت بـ pm2، وضع أمامه
  [Caddy](https://caddyserver.com) ليوفر HTTPS تلقائياً على دومين مجاني
  (مثل DuckDNS).
- **للتجربة فقط:** جهازك + نفق cloudflared (الرابط يتغير مع كل تشغيل،
  فحدّث الويب هوك في لوحة ميتا عند تغيّره).

```bash
npm install -g pm2
pm2 start src/index.js --name whatsapp-bot
pm2 save
```

## ملاحظة عن إشعارات الموظف

واتساب يسمح للبوت بإرسال رسائل حرة لأي رقم فقط خلال **24 ساعة من آخر
رسالة أرسلها ذلك الرقم للبوت**. لذلك ليصل إشعار الطلبات الجديدة للموظف:
يرسل الموظف أي رسالة (مثل "تمام") لرقم البوت مرة يومياً لإبقاء النافذة
مفتوحة. رسائل الموظف لا يرد عليها البوت بالقوائم (مستثنى من التدفق).

## هيكل المشروع

```
src/
├── index.js              # سيرفر الويب هوك + الإرسال عبر Graph API + إشعار الموظف
├── config/
│   ├── services.js       # كل الخدمات والأسعار والمستندات
│   └── messages.js       # نصوص رسائل البوت
├── bot/
│   ├── flow.js           # محرك المحادثة (المنطق الرئيسي)
│   └── stateManager.js   # تتبّع حالة كل محادثة
└── data/
    ├── store.js          # حفظ الطلبات في ملفات JSON
    ├── requests.json     # (يُنشأ تلقائياً) الطلبات
    └── media/            # (يُنشأ تلقائياً) المستندات المرسلة
```

## الطلبات

- الطلبات تُحفظ في `src/data/requests.json` مع رقم طلب متسلسل (`REQ-1001`, ...).
- المستندات المرسلة تُحفظ في `src/data/media/`.

هذه الملفات مستثناة من git (في `.gitignore`) لأنها تحتوي بيانات فعلية.

## تعديل الخدمات

كل الخدمات معرّفة كبيانات في `src/config/services.js`. لإضافة خدمة أو تعديل
مستند، عدّل هذا الملف فقط دون الحاجة لتغيير منطق البوت.

## التكلفة

- استقبال رسائل العملاء والرد عليها خلال 24 ساعة: **مجاني بلا حدود**.
- الرسائل التي يبدأها البوت خارج النافذة (قوالب تسويق/تنبيهات): بفلوس —
  البوت لا يستخدمها.
