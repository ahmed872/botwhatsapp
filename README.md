# بوت واتساب - مؤسسة الخدمات الإلكترونية

بوت واتساب يستقبل العملاء، يحدد الخدمة المطلوبة، يطلب المستندات اللازمة،
يحفظ بيانات العميل، ثم يحوّل الطلب للموظف المختص.

يعمل باستخدام مكتبة [whatsapp-web.js](https://wwebjs.dev/) — مجاني بالكامل،
ويعمل بمسح كود QR من رقم واتساب عادي (لا يحتاج حساب Meta التجاري).

## المميزات

- 🏠 قائمة رئيسية بالأقسام الثلاثة + متابعة طلب سابق + التحدث مع موظف.
- 👤 حفظ بيانات العميل تلقائياً (الاسم، الجوال، الهوية/الإقامة، المدينة).
- 📋 أكثر من 55 خدمة مقسّمة على 3 أقسام مع الأسعار والمستندات المطلوبة.
- ❓ أسئلة خاصة لبعض الخدمات (مثل فتح سجل تجاري، نقل الكفالة).
- 📎 استقبال المستندات (صور/ملفات/نصوص) وحفظها.
- 🔖 رقم طلب لكل عميل مع إمكانية المتابعة لاحقاً.
- 🔔 إشعار الموظف تلقائياً بكل طلب جديد على واتساب (اختياري).
- 👨‍💼 وضع "التحدث مع موظف" يوقف ردود البوت حتى يرد الموظف.

## الأقسام والخدمات

| القسم | عدد الخدمات |
|-------|-------------|
| 1️⃣ خدمات الأعمال والمنشآت | فتح سجل تجاري، ملفات (مكتب عمل/قوى/زكاة/تأمينات/غرفة)، نقل كفالة، رخص بلدية، تأشيرات، مدد، ضريبة، شطب... |
| 2️⃣ خدمات المواطنين | وكالات، حصر ورثة، صكوك، بنك التنمية، حساب المواطن، الضمان، تجديد جواز/أحوال، تسجيل تعليمي، قياس، حافز... |
| 3️⃣ خدمات العمال والمقيمين | أبشر، خروج وعودة، إقامة، رخصة عمل، زيارة عائلية، مواعيد مرور/نيابة، ناجز، كهرباء... |

الأسعار مأخوذة من قائمة أسعار المكتب ويمكن تعديلها من `src/config/services.js`.

## التشغيل

### 1. تثبيت الحزم

```bash
npm install
```

### 2. (اختياري) ضبط رقم الموظف

```bash
cp .env.example .env
# ثم عدّل EMPLOYEE_NUMBER برقم الموظف
```

لتشغيله فعلياً يمكنك تحميل ملف `.env` عبر `--env-file`:

```bash
node --env-file=.env src/index.js
```

### 3. التشغيل

```bash
npm start
```

سيظهر كود QR في الطرفية. افتح واتساب على جوالك:
**الإعدادات ← الأجهزة المرتبطة ← ربط جهاز** وامسح الكود.

بعد الربط تظهر رسالة `🚀 البوت جاهز`، ويبدأ الرد على أي عميل يراسل الرقم.

> يُمسح الكود مرة واحدة فقط؛ تُحفظ الجلسة في `.wwebjs_auth/`.

## هيكل المشروع

```
src/
├── index.js              # اتصال واتساب واستقبال/إرسال الرسائل + إشعار الموظف
├── config/
│   ├── services.js       # كل الخدمات والأسعار والمستندات والأسئلة
│   └── messages.js       # نصوص رسائل البوت
├── bot/
│   ├── flow.js           # محرك المحادثة (المنطق الرئيسي)
│   └── stateManager.js   # تتبّع حالة كل محادثة
└── data/
    ├── store.js          # حفظ العملاء والطلبات في ملفات JSON
    ├── customers.json    # (يُنشأ تلقائياً) بيانات العملاء
    ├── requests.json     # (يُنشأ تلقائياً) الطلبات
    └── media/            # (يُنشأ تلقائياً) المستندات المرسلة
```

## بيانات العملاء والطلبات

- بيانات العملاء تُحفظ في `src/data/customers.json`.
- الطلبات تُحفظ في `src/data/requests.json` مع رقم طلب متسلسل (`REQ-1001`, ...).
- المستندات المرسلة تُحفظ في `src/data/media/`.

هذه الملفات مستثناة من git (في `.gitignore`) لأنها تحتوي بيانات فعلية.

## تعديل الخدمات أو الأسعار

كل الخدمات معرّفة كبيانات في `src/config/services.js`. لإضافة خدمة أو تعديل
سعر أو مستند، عدّل هذا الملف فقط دون الحاجة لتغيير منطق البوت.
